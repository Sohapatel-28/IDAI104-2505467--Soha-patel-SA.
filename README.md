# IDAI104-2505467--Soha-patel.
TechLift Elevator Analytics is a Streamlit dashboard for predictive maintenance of elevator systems. It analyzes real-time sensor data including revolutions, humidity, and vibration to detect anomalies, visualize trends, and provide maintenance insights — helping engineers prevent failures before they occur.
About:
This dashboard was built for TechLift Solutions, an engineering firm working to improve elevator efficiency in tall buildings. The app analyzes elevator sensor data sampled at 4Hz during peak evening hours and performs full Exploratory Data Analysis (EDA) on sensor readings including revolutions, humidity, vibration, and auxiliary signals x1 to x5. The main goal is to understand what factors drive vibration — the key health indicator of elevator door mechanisms — so that engineering teams can make smarter, data-driven maintenance decisions before failures happen and before costly downtime occurs.
The dataset comes from sensors attached to elevator doors, collecting real-time operational data. Vibration is the target variable because elevated vibration levels indicate mechanical wear, bearing stress, or possible failure in the door system. By carefully analyzing how environmental factors like humidity and operational factors like revolution counts affect vibration over time, maintenance teams can shift from reactive repairs to proactive predictive maintenance — reducing unexpected breakdowns, extending equipment life, and saving significant costs for building operators.

Features:
Data Overview — The app automatically cleans the uploaded dataset by removing duplicate rows, filling missing values with column medians, and converting all columns to their correct numeric data types. A full cleaning report is displayed showing exactly how many duplicates were removed and how many missing values were handled. Alongside this, a statistical summary table shows the mean, standard deviation, minimum, maximum, and percentile values for every sensor column. The first 10 rows of the cleaned dataset are shown so users can verify the data before analysis begins. A data completeness bar chart visually confirms that all columns are 100% complete with no missing values, giving confidence that the analysis is based on clean, reliable data.
Time Series — A three-panel interactive line chart tracks how vibration, revolutions, and humidity change across the selected sample of readings over time. Each panel is stacked and shares the same time axis so users can visually compare trends across all three signals simultaneously. Anomaly spikes where vibration exceeds the user-defined threshold are highlighted with gold star markers directly on the vibration panel, making it easy for engineers to pinpoint exactly when and where mechanical stress events occurred. Key statistics including peak vibration, anomaly spike count, and maximum revolutions are displayed as metric cards below the chart.
Distributions — Three histograms display the statistical spread of the most important sensor readings — humidity, revolutions, and vibration. Each chart includes a dashed yellow mean line so users can immediately see the average operating value. The vibration histogram also includes a red anomaly threshold line, visually separating the normal operating zone from the critical zone. This helps engineers quickly understand whether the elevator fleet is generally operating within safe limits or whether a significant portion of readings are falling into the danger zone.
Scatter Analysis — A fully interactive scatter plot allows the user to choose any combination of X axis, Y axis, and color variable from dropdown menus, making it possible to explore relationships between any two sensors in the dataset. A yellow trend line is automatically calculated using polynomial fitting and displayed with its slope value, showing whether the relationship is increasing or decreasing. Anomalous readings are overlaid as orange star markers so problem data points stand out clearly. The Pearson correlation coefficient is calculated and displayed below the chart along with a strength label — Strong, Moderate, or Weak — helping users quickly interpret what the scatter pattern means in engineering terms.
Box Plots — Two box plot charts provide a detailed view of data distribution and outlier behavior. The first shows the spread, median, interquartile range, and individual outlier dots for each of the five auxiliary sensor channels x1 to x5 side by side, making it easy to compare which sensors behave consistently and which ones produce irregular spikes. The second box plot groups vibration readings into four humidity categories — Low, Moderate, High, and Very High — and displays a separate box for each group, clearly showing how vibration levels rise as humidity increases across the dataset.
Correlation Heatmap — A full Pearson correlation matrix heatmap shows the pairwise relationship between all eight numeric features in the dataset. The color scale runs from red for strong positive correlation to blue for strong negative correlation, with exact values printed inside each cell for precision. Hovering over any cell shows a tooltip with the exact feature pair and correlation value. Below the heatmap, a ranked bar chart displays each feature's individual correlation with the vibration target variable, color-coded from green to red, so engineers can instantly see which sensors are the most important predictors of vibration and where to focus monitoring efforts.
Live Explorer — An interactive real-time simulator allows any user to manually adjust three sliders controlling door revolutions, humidity percentage, and sensor x3 value. As the sliders move, the estimated vibration level is recalculated instantly using the statistical model derived from the dataset. The result is displayed as a large number with a color-coded status label — green for Normal, yellow for Warning, and red for Critical — along with an animated gauge chart that visually shows where the value sits relative to the safe and danger zones. A context scatter plot below the gauge shows the full historical dataset as grey dots, with the user's simulated point appearing as a large gold star, making it easy to see whether the simulated conditions are typical or unusual compared to real past data.
Insights — Four data-driven insights are presented based on the full statistical analysis, covering the impact of revolutions on vibration, the role of humidity in mechanical wear, the anomaly detection rate across all readings, and the identification of sensor x3 as the strongest early-warning indicator among the auxiliary signals. Four concrete maintenance recommendations are provided for engineering teams based on these findings, advising on revolution thresholds, humidity control measures, sensor alert configurations, and inspection scheduling. A summary table displays the current status of five key metrics — average vibration, maximum vibration, average revolutions, anomaly rate, and average humidity — each labeled as Normal, Monitor, or Critical to give a quick operational health snapshot of the elevator fleet.
